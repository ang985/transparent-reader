背景浓度 20%
0% 只留文字几乎全透明；调高更像一张磨砂卡片，也更不容易被看清。
正文字号 100%
只放大文字，版式和图片不动。Ctrl+滚轮是整页缩放，两者可以叠加。
自动滚动速度 60
点击阅读层工具条的 ⇓ 开始自动滚动；手动滚一下或按方向键即暂停。单位：像素/秒。
隐藏图片 只留文字，最不显眼
专注模式 去掉页头、导航、广告、评论区
始终置顶 勾上后压在所有窗口上面；关闭后可被其它窗口盖住
锁定窗口大小 打开后拖窗口边缘不再改变大小，抓滚动条不会误拖
工具条常亮 顶部导航条始终完全显示，鼠标移开也不变淡
全局唤出热键 被别的程序盖住时，按一下把浮层提到最前并聚焦（全局生效）
怎么用
  • 顶部工具条鼠标移到浮层顶端出现：‹ 后退、› 前进、↻ 刷新、⋯ 设置、— 收起、× 关闭
  • 换页面只有一个阅读层：在面板里填新网址点「打开」，会直接在当前窗口跳转
  • 滚轮 / 左键翻页、点链接、点选项，和正常浏览器一样
  • Ctrl + 滚轮缩放页面（Ctrl + / − 或 Ctrl+0 复位），顶部工具条不跟着缩放
  • Alt + Q收起成小胶囊；在胶囊上再按一次恢复
  • Alt + P在阅读层 / 胶囊上唤出这个控制面板
  • Alt + 滚轮直接调背景浓度（上滚更浓、下滚更淡），不用回面板拖滑块
  • Alt + T临时穿透：鼠标可以直接点到下层窗口，再按一次 Alt+T 退出
  • 全局唤出默认 Alt + R：窗口被别的程序盖住、或压根没焦点时，按一下把它提到最前并聚焦。可在上面的设置区改键或关掉
  • 按站点记忆每个网站单独记住自己的浓度和缩放，切站点自动切回来
  • Alt + ← / →后退 / 前进
  • Alt + 拖动在页面任意位置整体挪动窗口
  • 窗口边缘需先在面板关闭「锁定窗口大小」，才能拖动边缘调整大小
  • Esc关闭阅读层
  • 托盘图标单击把浮层唤到最前，双击打开面板，右键更多操作
